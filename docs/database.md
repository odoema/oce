# OCE Data Model

| Sheet | Purpose |
|---|---|
| CONTACTS | Normalized master contact records |
| IMPORT | Staging area for authorized contact imports |
| SEGMENTS | Reusable targeting rules |
| CAMPAIGNS | Campaign definitions and status |
| QUEUE | Batch-level dispatch queue |
| HOLIDAYS | National/international blocked dates |
| SEND_LOG | Delivery audit trail |
| SETTINGS | Runtime configuration |
| DASHBOARD | Operational metrics |
| SUPPRESSION | Unsubscribe, bounce, and other suppression records |

No live contact data belongs in this repository.
