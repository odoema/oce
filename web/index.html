Pipeline

  1. DiscoverWikipedia, Wikidata and official registers pick public starting pages. Free, no key.
  2. CollectPolite crawler: robots.txt, budgets, retries, no login/CAPTCHA bypass.
  3. ReviewYou approve each contact and record the lawful basis.
  4. SendOnly eligible contacts, inside the sending window, with one-click unsubscribe.
